# Antigravity Agent Guidelines

- **Git Auto-Push**: Setiap kali selesai melakukan perbaikan kode, penambahan fitur, atau modifikasi file atas permintaan user, lakukan secara otomatis:
  1. `git add` pada file yang diubah
  2. `git commit -m "<pesan commit yang jelas>"`
  3. `git push origin main` ke repository GitHub
